PRA

Toward Cross-Rubric Surgical Skill Assessment via Joint Embedding Prediction

Jiajun Cheng1, Haidar M. Abdul-Muhsin2, Juha Choi1, Shan Lin1

1Arizona State University  ·  2Mayo Clinic

Abstract

Expert review of surgical videos is essential for surgical training but labor-intensive, motivating AI-assisted skill assessment to provide feedback at scale. Although surgical assessment rubrics may use different language to describe similar skills, existing automated methods commonly predict predefined skill levels or numerical scores tied to fixed rubrics, limiting their ability to transfer across semantically equivalent assessment criteria. We propose Predictive Rubric Alignment (PRA), a joint embedding prediction approach that scores surgical videos using natural-language descriptions of skill levels. Rather than matching level probabilities, PRA predicts a rater-weighted combination of skill-level description embeddings. Adjacent description features define a score-parameterized path, and the predicted embedding is projected onto this path to read the score. We introduce two variants: PRA-item, which uses learned queries for predefined assessment items, and PRA-cond, which generates queries from textual item names to enable assessment of unseen items without retraining. On AIxSuture, a dataset of expert-rated suturing videos, PRA outperforms published baselines in skill classification. We further evaluate zero-shot transfer to the smaller surgical skill assessment benchmark JIGSAWS. Trained on only two AIxSuture rubric items, PRA-cond assesses unseen JIGSAWS items without further training, yielding positive score correlations and greater Grad-CAM overlap with instruments and suture than a description-matching baseline. These results support predictive rubric alignment as a promising direction for flexible and explainable automated surgical skill assessment.

Contributions

  1. PRA, which formulates surgical skill scoring as predicting a rater-weighted combination of performance-level description embeddings and reads the score by projection onto the description path, providing an alternative to level-probability matching.
  2. PRA-cond, which accepts rubric item names and performance descriptions as text, enabling zero-shot assessment of rubric items not used during training.
  3. An evaluation on AIxSuture and zero-shot transfer to JIGSAWS: improved AIxSuture performance over published baselines and same-encoder controls, positive zero-shot score correlations, and greater Grad-CAM overlap with instruments and suture than a description-matching baseline.
